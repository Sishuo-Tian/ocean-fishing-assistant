# 远洋捕捞辅助系统

Ocean Fishing Assistant 是一个处于需求调研与开发准备阶段的学生研究项目，围绕远洋捕捞场景，探索水下图像分割与作业信息管理。

> 目前仅完成项目规划，尚未包含可运行的前后端或模型服务。下列功能均为规划或待调研内容。

## 项目目标

以水下开放词汇语义分割为研究主线，逐步搭建连接图像分析、作业记录与数据统计的辅助系统。

## 功能规划

| 模块 | 规划内容 | 当前状态 |
| --- | --- | --- |
| 综合驾驶舱 | 地图、作业概览、最近分析记录 | 待设计 |
| 海洋气象与海况 | 天气、风速风向、浪高及变化趋势 | 待确认数据来源 |
| 航线与作业区域 | 手动规划作业点、航线与轨迹展示 | 待设计 |
| 水下图像分析 | 图片上传、分割预测、结果对比与历史记录 | 待接入模型 |
| 作业与鱼获管理 | 时间、位置、鱼种、重量与图片记录 | 待开发 |
| 数据统计 | 作业次数、鱼获构成与分析记录统计 | 待开发 |
| 视频跟踪与计数 | 视频内鱼类编号、轨迹与过线计数 | 可行性调研 |
| 鱼获参考价值 | 结合确认鱼种、实测重量和价格来源估算 | 可行性调研 |

## 技术方案候选

- 前端：Vue 3 + Element Plus。
- 后端：Python + FastAPI。
- 模型：PyTorch，先复现基础方法，再适配水下数据。
- 数据存储：初期使用 SQLite，图片单独保存。

最终方案根据团队经验和实验条件确定。

## 数据与文件管理

- 提交代码、配置、研究笔记与少量有使用权限的示例图片。
- 数据集、视频和模型权重单独保存，文档中记录获取方式。
- 不提交密码、密钥、个人隐私或未经授权的数据。
- 演示数据明确标注，实验指标仅填写实际验证结果。
- 分割像素占比不直接等同于鱼的数量、重量或经济价值。
